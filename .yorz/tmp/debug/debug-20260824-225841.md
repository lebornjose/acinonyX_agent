## Debug 2 · 中文股票名称未能解析

- 状态：debugging
- 快照：40cbe9c9fd3e1bc6535f82ea3792095a01b28bf8
- 进入时间：'2026-08-24 23:05:14'

### 2.1 Bug 现象与复现

- 用户输入自然语言中文股票问题后，页面直接显示“未能识别 A 股代码，请提供股票名称或 6 位股票代码。”
- 期望：模型先从中文问题中抽取股票名称或代码，再由同花顺数据接口查询；不在 A 股覆盖范围内的标的应得到可读说明。

### 2.2 关联链路分析

`用户中文问题` → `prepare` → `stock_analysis.searchKeyword` → `同花顺 A 股标的检索` → `stockData` → `writer`。

### 2.3 Debug 基线

- 快照：40cbe9c9fd3e1bc6535f82ea3792095a01b28bf8
- 进入时间：'2026-08-24 23:05:14'

### 2.4 假设看板

- 已确认：当前正则去词后取首段的策略会把自然语言中的“问复星医药”等残留文本当作股票名称，导致同花顺 A 股标的检索失败。
- 已确认：独立模型标的解析节点可以输出“复星医药”，并由同花顺接口确定性解析为 `600196.SH`。
- 已确认：未识别或非 A 股标的不再中断主回答，而是向 writer 注入数据覆盖范围说明。

### 2.5 证据

- `stock-analysis.tool.js` 中的 `searchKeyword` 仅通过正则去掉部分词语后取第一个空格分段，不理解中文语义。
- 对“请问复星医药股价怎么样”而言，去词后仍会留下“问复星医药 怎么样”，首段并非股票名称。
- 同花顺客户端使用 `resolveAshare`，数据能力仅按 A 股标的解析；港股腾讯等标的不在当前工具覆盖范围。

### 2.6 根因与修复

- 根因：行情工具承担了自然语言语义解析职责，`searchKeyword` 的规则去词无法正确处理连续中文句子。
- 修复：新增 `stock_symbol` Agent，严格要求只输出唯一 A 股股票名称或代码；`stock_analysis` 工具接收该值并继续负责同花顺确定性检索、消歧和计算。
- 兜底：解析为空或同花顺无法匹配时，图返回 `stockDataNotice` 给 writer；当前数据源范围外的港股、美股等不会再将底层错误传到前端。

### 2.7 验证与收尾

- `node --check` 已通过新增 Agent、图、运行时、工具和 writer 文件。
- `node --test` 已通过标的解析与后续问题推荐共 4 条测试。
- 真实运行时回归：`请问复星医药近期的股价和估值怎么样？` 返回 `600196.SH`、`复星医药` 和完整回答；`腾讯股价怎么样？` 返回空行情和 A 股覆盖范围提示，并仍生成回答。
- 已重启 4002 Agent Service；`GET /internal/health` 返回 `{ "ok": true }`。
