# Skill 设计模板

每个运行时 Skill 至少包含一个 `SKILL.md`，并写清以下内容：

```markdown
---
name: unique-skill-name
description: 明确说明能力和触发场景
---

# Skill 名称

## 触发条件
- 应触发：
- 不应触发：

## 输入与输出
- 输入字段、类型和必填性：
- 输出结构和质量要求：

## 执行流程
1. 
2. 

## 限制与失败
- 不确定信息如何标注：
- 工具或模型失败如何返回：

## 示例
✅ 输入：
✅ 输出：
❌ 输入：
```

Skill 应保持单一职责；通用规则放在主文件，行业知识、长示例和参考资料放入 `references/`。
