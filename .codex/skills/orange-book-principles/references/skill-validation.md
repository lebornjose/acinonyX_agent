# Skill 验证清单

每个 Skill 至少准备四类样例：

1. 正常触发：明确命中 Skill 的输入。
2. 不触发：相邻但不属于该 Skill 的输入。
3. 边界输入：空值、超长文本、缺字段和不确定信息。
4. 失败路径：模型失败、工具失败或参考资料缺失。

检查结果：

- [ ] 触发条件可观察，且不会误伤相邻任务。
- [ ] 输出满足字段、语言、格式和长度约束。
- [ ] 不编造来源、工具结果或成功状态。
- [ ] 错误可识别，且不泄露密钥、堆栈或完整上游错误。
- [ ] Agent 的输入输出与 Graph 状态字段一致。
- [ ] JavaScript 执行 `node --check`。
- [ ] agent-service 验证 `/internal/health`。
- [ ] 相关 workspace 测试或构建通过。

验证报告应记录样例、期望行为、实际行为和未解决问题；不要只记录“测试通过”。
